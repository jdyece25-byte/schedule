# 현재 일정 운영 메모

사용자가 2026-09-14 제공한 일정과 시간표를 반영했다. 일정 원본은 `events.json`이다.
기존 6월 일정 76건은 과거 기록으로 보존하며 현재 일정으로 반복하지 않는다.

## 등록 범위와 표기

- 반복 일정은 2026-09-14부터 2026-12-31까지 날짜별로 등록했다. 이전 날짜는 소급 생성하지 않았다.
- 이 기간은 사용자가 요청한 등록 범위다. 학기 종강일, 공휴일 휴강이나 연말 취소를 확정한 것은 아니다. 별도 공지가 없으면 임의 취소하지 않는다.
- 신규 이벤트의 `id`는 개별 일정 식별자, `series`는 같은 반복 일정 묶음이다. 수정 시 식별자를 유지한다.
- 시각은 한국 시간 기준 자정 이후 분이다. `e:1440`은 그날 밤 자정 종료다.
- 시간이 미정인 일정과 시각이 없는 제출 마감에는 `s`/`e`를 임의로 넣지 않는다.
- `status:tentative`는 미결정 일정이다. 거시경제이론은 드랍 결정 전까지 유지한다.
- 장소 간 이동시간을 추측하지 않는다. 새 장소는 `travel.json.locations`에만 추가했고 소요시간은 미확인이다.
