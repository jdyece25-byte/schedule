# Birthday scene

`birthday-night.webp` is an AI-generated photorealistic scene created for this app
with OpenAI image generation on 2026-10-19 (Asia/Seoul). It depicts a Milky Way
night sky and an ivory buttercream cake. It is not a photograph of an actual
location or an image downloaded from a photographer.

The original 1024 × 1536 PNG was encoded as WebP quality 88 for mobile loading.
The candle, flame, smoke and fireworks are interactive HTML/CSS/canvas layers;
the image contains no candle. The asset is served locally with the website.
