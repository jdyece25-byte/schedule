⚙ 일정 요청 연결

Fine-grained 토큰 만들기 ↗에서 본인 계정 → Only select repositories → schedule-requests만 선택하고 Contents를 Read and write로 설정하세요. 요청 저장소는 비공개여야 합니다. 토큰은 이 브라우저에만 저장됩니다. 이 토큰에는 공개 schedule 저장소 권한이 필요하지 않습니다.

기존 직접 편집 · Gemini 추천 설정

직접 추가·이동시간 편집과 AI 추천에만 사용하는 별도 설정입니다. 자연어 일정 요청은 위 연결 설정을 사용합니다.
설정은 이 브라우저에만 저장됩니다 (localStorage). 파일에 기록되지 않습니다.
GitHub PAT: github.com → Settings → Developer settings → Personal access tokens → repo 권한
Gemini API: aistudio.google.com → Get API key (무료)
